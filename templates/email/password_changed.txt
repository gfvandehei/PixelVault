{# Plain-text part of the password-change notice — the part that always renders.

   Same rules as invite.txt: this is the copy that has to survive a text-only
   client, a screen reader, a spam-quarantine digest and a phone preview, so every
   fact is stated in words rather than in layout.

   One rule specific to this message: it contains no link. There is no password
   reset flow yet (issue #33), and a security notice whose call to action is "click
   here" is indistinguishable from the phishing mail it invites. The action offered
   is contacting a person.

   Not autoescaped — Jinja escapes .html templates only — so keep every value here
   inside plain prose.
